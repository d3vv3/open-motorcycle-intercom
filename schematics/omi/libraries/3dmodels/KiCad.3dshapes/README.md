# KiCad Standard 3D Models

This directory contains the nine standard STEP models used by OpenHelmet Rev2.
They are stored with the project so the 3D viewer and STEP export work without
a separate system installation of KiCad's model library.

Source: [KiCad/kicad-packages3D](https://github.com/KiCad/kicad-packages3D),
revision `b8b3cfdfad88ba66f21002b3de51dc6f7d55ba5a`.
The files are unmodified upstream assets. `sources.json` records their original
paths and SHA-256 hashes. Attribution: KiCad library contributors, including the
authors identified in each STEP file's header.

These assets use CC-BY-SA 4.0 with the KiCad library exception; see `LICENSE.md`.
The upstream library license applies to this model collection.

Passive models represent nominal package geometry, not guaranteed dimensions
for every selected manufacturer part. Use component datasheets for mechanical
clearance sign-off. DNP footprints remain intentionally unpopulated.
